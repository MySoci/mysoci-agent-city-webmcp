## Exact narration draft

**0:00–0:12**

“For newcomers and small groups, choosing an event is only half the work. MySoci Agent City brings friends, availability and a meeting place into one shared plan—with human approval.”

**0:12–0:30**

“This standalone challenge prototype exposes nine native WebMCP tools. Here is the client's discovered tool list and a real event-search call. The result appears in Agent Activity. The agent uses structured capabilities, not guessed buttons or browser automation.”

**0:30–0:48**

“Judge Mode offers a no-login, deterministic replay using those same registered tools. I'll start the social meetup scenario: find an AI or music event, prioritize available nearby friends, and recommend a place to meet.”

**0:48–1:08**

“The search selects Neural Nights. Its interests and neighborhood become the shared context for the following tools. This is one visible plan, not an agent working in a separate hidden copy.”

**1:08–1:28**

“Next, WebMCP composes friendships, interests, availability, privacy-safe presence, and places. Leo is nearby only at neighborhood level. Amina is city-only, so the tool never upgrades her to nearby. Hidden people are excluded, and no person has precise coordinates.”

**1:28–1:48**

“The agent proposes this meetup, but it cannot approve it. I can change the group first, so I’ll remove Amina. That human edit updates the same shared state the next agent action will read.”

**1:48–2:04**

“Now I confirm the meetup. Invitations have a separate approval gate, and this sandbox never contacts a real person. After I approve, only Leo’s fictional status changes to Invite prepared.”

**2:04–2:16**

“The action remains reversible. Cancel removes the meetup consistently, and Reset returns the entire demo to its original seeded state for another judge.”

**2:16–2:28**

“Native registration, strict schemas and automated privacy checks support this flow. Tests also reject agent-supplied confirmation without human approval, including stale or cancelled approvals.”

**2:28–2:37**

“A working challenge prototype informing MySoci’s future agent layer—not the full MySoci product. Shared social planning, with people in control.”
